# 신규 서비스 메모 (가상)

- 서비스명: 리포트봇 (가칭)
- 한 줄 설명: 사내 엑셀 데이터를 올리면 경영 보고용 요약과 차트를 자동으로 만들어 주는 SaaS
- 대상: 중견기업 기획·재무팀 (직원 300~2,000명)
- 문제: 월간 보고서 작성에 팀당 월 40시간 소요, 수치 오류로 재작성이 잦음
- 해결: 데이터 연결 → 자동 집계 → 템플릿 보고서 생성 → 검토 후 배포
- 경쟁: 엑셀 수작업, BI 도구(학습 비용 큼), 외주 보고서
- 차별점: 한국식 보고서 양식(개조식, 거버닝 메시지) 기본 지원, 설치 없이 2주 도입
- 가격: 팀 플랜 월 49만 원, 엔터프라이즈 별도 협의
- 일정: 2026년 11월 베타, 2027년 1분기 정식 출시
- 요청: 파일럿 고객사 3곳 확보를 위한 영업 지원
