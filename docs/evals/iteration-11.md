기준선 대비 토큰 -22%, 시간 -57%. 6회차와 비교하면 토큰은 비슷하고 시간은 11% 줄었다. 평가 5는 통계 연결이 막힌
상태에서 숫자를 지어내지 않고 "데이터 대기" 장표와 다운로드 안내로 끝내 토큰이 조금 늘었다.

처음 채점에서 평가 4(친근한 문체 비율)와 평가 5(GDP 장표)가 1건씩 실패했지만 모두 채점기 문제였다. 평가 4는
가격 항목·범례 같은 라벨까지 문장으로 세었고, 평가 5는 숫자 없는 대기 장표를 미검증 수치로 보았다. 문장만 세도록,
대기 장표는 통과로 고쳤다.

## 실행 중 나온 개선점과 조치

| 개선점 | 조치 |
|---|---|
| patch에서 차트와 노트를 함께 고쳐도 "노트에 옛 기간이 남음" 경고 | 모든 연산을 적용한 뒤 검사 |
| 구성안 뼈대의 마지막 장 제목이 문장이라 빌드 경고 | 뼈대가 `# 요청 사항` 라벨과 `ask: "TODO ..."`를 씀 |
| `pptkit plan`이 질문 10개를 출력(첫 메시지는 5개 제한) | 출력에 "최대 5개, 답이 있는 것은 빼고 앞에서부터" 명시 |
| '회사 소개'가 피칭인지 영업인지 모호 | `pptkit plan`이 청중을 물으라고 안내(투자자/고객/신입) |
| `formality: neutral`이 조용히 무시됨 | neutral은 ~합니다 문장체, 모르는 값은 NOTE |
| 시안 빌드가 시안에 없는 장의 경고를 구분 없이 출력 | "(deck.md slide, not in the sample)" 표기 |
| 데이터 파일이 없으면 트랙션 장의 지표 타일까지 사라짐 | 지표는 남기고 차트 자리만 대기 상자 |
| 대기 경고가 필요한 열을 알려 주지 않음 | 필요한 열과 "데이터가 오면 결론 제목으로" 안내 |
| World Bank 다운로드 파일 이름이 매번 바뀜 | `data: API_NY.GDP*.zip` 패턴, 가장 최근 파일 사용 |
| KOR/JPN/USA를 한국/일본/미국으로, 2026을 (잠정)으로 표시할 방법 없음 | `labels:`가 계열 값과 범주(축·표 행)에도 적용 |
| `pptkit spec`에 공공 데이터 열 이름이 없음 | 차트 패턴 출력에 labels·공공 데이터 파일 절 포함 |
| 요금제마다 같은 기능이 반복됨, 미정 가격 안내 없음 | `common:`(공통 기능 한 줄), deck-spec에 `price: 별도 협의` 안내 |
