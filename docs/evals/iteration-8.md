- `pptkit spec <패턴|차트> ..`: 쓰는 패턴의 키만 출력(인자 없으면 공통 규칙과 이름 목록)

- `pptkit data a.csv b.csv`: 여러 파일을 한 번에 요약

## 실행 중 나온 개선점과 조치

| 개선점 | 조치 |
|---|---|
| 톤 시안(`--sample`)이 그리지 않은 장표의 긴 문장을 놓침 | 시안 빌드도 모든 장표의 내용 점검(WARN은 deck.md 순번) |
| 같은 매출이 chart-table 표는 819, heatmap은 818.8 | 표는 10만 미만이면 소수 첫째 자리 유지 |
| 가중 평균 이익률 0.3617을 %로 직접 환산 | `--percent`가 wmean에도 쓰이고 소수 첫째 자리로 출력됨을 SKILL에 명시 |
| 진척 장표가 96%와 99.5%를 섞어 표시, 제목(95.6%)과 불일치 | 달성률은 항상 소수 첫째 자리 |
| 실적 - 목표 금액을 구할 방법이 없음 | `pivot --val actual --minus target` |
| 지역별 chart-table에 합계 행이 없음 | 범주 표 끝에 합계 행(굵게, 구분선), 증감률 포함 |
| 지역 × 기간 묶은 막대를 찾기 어려움 | deck-spec의 column-trend 설명에 `x: region, series: quarter` 용례 추가 |
