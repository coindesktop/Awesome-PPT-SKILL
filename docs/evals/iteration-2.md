# 평가 2회차 (2026-10-03)

실행: 평가 5개 × 스킬 사용 1회. 기준선(스킬 미사용)은 평가 3만 새로 실행했고, 평가 1·2·4·5는 1회차 기준선을 재사용했다.
디자인은 DESIGN.md 4종으로 고도화한 뒤 실행했다.

|---|---|---|---|---|---|---|
| 1 첫 사용·본부장 보고 | 7/7 | 6/7 | 79,148 | 108,663 | 118s | 235s |

- 토큰 -25%, 시간 -54%. 서브에이전트 고정 오버헤드(약 6만 토큰)를 포함한 값이다.
- 평가 3은 기준선이 python-pptx로 직접 고쳐도 토큰이 비슷했다. 수정 작업은 스킬의 이점이 작다.

## 육안 비교

- 1회차에서 기준선이 앞섰던 시각 품질은 이번에 역전됐다. 차트+표, 차트 2개, 100% 누적, 히트맵 표, 어두운 결론 장표가 모두 네이티브 객체로 나왔다.
- 평가 4는 forest 디자인과 경어체로 "딱딱하지 않게"가 반영됐다.
- 남은 약점: 내용이 짧은 장표(process, compare-table, 불릿 4개)의 아래쪽 40%가 비었다.

## 실행 중 발견한 결함과 조치

| 결함 | 조치 |
|---|---|
| `pivot`에 `--cols`가 필수라 1차원 집계를 못 함(평가 1·2·3) | `--cols` 선택, 시간 열은 시간순 정렬, CAGR 출력 |
| 증감률·비중을 모델이 직접 계산함 | `--pct row\|col\|growth` |
| `wmean`에 합계가 없음 | 가중 평균 합계 행·열 |
| `data`가 범주를 6개에서 잘라 최신 분기가 안 보임 | 시간 열은 처음..끝 범위와 마지막 3개 표시 |
| 비중 차트에 공통 단위 '억 원'이 붙음 | `stacked-share`/`fmt: pct`는 `%` 기본값 |
| '자료: 자료:' 중복 | 출처 접두어 제거 후 디자인이 붙임 |
| closing에서 `# 제목`이 조용히 사라짐(3회 지적) | 짧은 제목은 라벨로 표시, 긴 제목은 WARN |
| friendly인데 VOICE formal로 표시됨, 콜아웃 제목 '시사점' 고정 | friendly 문체 추가, 문체별 콜아웃 제목(핵심/시사점) |
| 아래쪽 공백을 qa가 못 잡음 | 본문 균형 배치(4:6), 불릿이 적으면 글자 확대, qa `sparse` 경고 |
| `map --changed`가 차트 값·노트 변경을 못 잡음, `.map.json`을 덱 옆에 남김 | 해시에 차트 데이터·노트 포함, 캐시를 `~/.pptkit/maps`로 이동 |
| `fix: overlap`이 가로 정렬을 하지 않음 | `stack: [ids]` 연산 추가 |
| World Bank 실패 시 대안이 막연함 | 웹 다운로드 주소 출력, World Bank 웹 CSV 자동 정리 |
